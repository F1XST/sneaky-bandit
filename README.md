# Sneaky Bandit — ย่องเบา

เกมแนว stealth มุมมองบน ทำด้วย HTML + CSS + JavaScript ล้วน ไม่ต้องติดตั้งอะไร
เปิด `index.html` ได้เลย (ต้องต่อเน็ตเพื่อโหลดฟอนต์ Kanit) หรือเอาขึ้น GitHub Pages (Settings → Pages → Branch: main / root)

## วิธีเล่น
| ปุ่ม | ทำอะไร |
|---|---|
| WASD / ลูกศร | เดิน |
| Shift | ย่อง (ช้า แต่ไม่มีเสียง) |
| คลิก / Space | โยนไอเท็มที่เลือก |
| 1 / 2 / 3 | เลือก หิน / ยาสลบ / ตัวหลอกเสียง |
| 4 / 5 | ใช้ชุดยามปลอมตัว / รองเท้าเงียบ ทันที |
| Tab | มุมมอง AI (สถานะ เส้นทาง ระยะวิทยุของยาม) |
| P / Esc | หยุดเกม |
| R | เริ่มด่านใหม่ |
| U / C (หน้าเลือกด่าน) | ปลดล็อกทุกด่าน / เพิ่มเหรียญ 1000 (ไว้เดโม) |

บนมือถือใช้จอยสติ๊กซ้ายล่าง ปุ่ม Shift (สลับย่อง) ขวาล่าง และแตะที่แผนที่เพื่อโยนไอเท็ม (เล่นแนวนอน)

ดาว 3 ดวง: ทำภารกิจสำเร็จ · เสร็จทันเวลาเป้าหมาย · ไม่ถูกยามเห็นเลย
ต้องได้อย่างน้อย 1 ดาวในด่านก่อนหน้า ถึงจะปลดล็อกด่านถัดไป

## ฟีเจอร์
- **20 ด่าน** 5 ด่านออกแบบมือ + 15 ด่านสร้างด้วย `js/levelgen.js` (seed คงที่ ตรวจแล้วว่าเดินถึงของและกุญแจทุกชิ้น)
- **โหมดสุ่มไม่จบ** สร้างอาคารใหม่ทุกด่าน ยากขึ้นตามจำนวนด่านที่ผ่านต่อเนื่อง
- **โหมดเร่งด่วน** ตำรวจเสริมเข้ามาทุก 40 วินาที เหรียญ ×1.5
- **ร้านค้า**: เหรียญจากของที่ขโมยใช้ซื้ออัปเกรดถาวร 8 แบบ และตัวละคร 4 ตัว (บ็อบ ลูน่า แมกซ์ ไอริส) ที่ความสามารถต่างกัน
- **สถิติ**: เวลาที่ดีที่สุดของแต่ละด่าน ดาวรวม สถิติโหมดสุ่ม
- **สิ่งกีดขวาง**: กล้องวงจรปิด เลเซอร์ติด/ดับ ประตูล็อกที่ต้องหากุญแจ
- **ไอเท็ม**: หิน ยาสลบ ตัวหลอกเสียง ชุดยามปลอมตัว รองเท้าเงียบ
- **ยามชนิดต่าง ๆ**: ยามทั่วไป ตำรวจ ยามเฝ้าจุด หมาตำรวจ (ดมกลิ่น) ยามขี้เซา (ตื่นเมื่อได้ยินเสียงใกล้ ๆ)
- **ตัวช่วยสอน** ทีละขั้นในด่านแรก, ดนตรีและเสียงสร้างเอง (WebAudio), ภาพเคลื่อนไหวตอนผ่านด่าน/ถูกจับ, สลับภาษาไทย/อังกฤษ

## ส่วนที่เกี่ยวกับ Multi-Agent
| แนวคิด | อยู่ที่ไหนในโค้ด |
|---|---|
| Agent architecture (perception / beliefs / FSM) | `js/guard.js` |
| **Contract Net Protocol**: ผู้ที่เห็นผู้เล่นประกาศงานค้นหา (CFP) ยามที่ว่างเสนอราคา (ระยะเดิน + ความไม่อยากทิ้งจุด) และงานถูกมอบให้ราคาต่ำสุด | `G.cnp` ใน `js/game.js` |
| **การสื่อสารระยะจำกัด** วิทยุไกล 300px ยามที่อยู่นอกระยะไม่รู้เรื่อง จนกว่ายามที่รู้เดินเข้ามาในระยะแล้ว **ส่งต่อข่าว (relay)** | `G.radioBroadcast`, `relayTick` |
| **การเรียนรู้**: นับครั้งที่ผู้เล่นหลบพุ่มไม้แต่ละต้น ยามจะไปตรวจที่ซ่อนที่จำได้ก่อน | `pickHide` ใน `guard.js`, `G.memory` |
| **Reactive vs Deliberative**: ตั้งค่าได้ในเมนูตั้งค่า (มีแผน / ตอบสนองตรง ๆ / ผสม) ยาม reactive ไม่ใช้วิทยุ ไม่จำ ลืมเร็ว | `brain` ใน `guard.js` |
| Heterogeneous agents: ยามทั่วไป ตำรวจ หมา (smell) ยามขี้เซา ยามเฝ้าจุด | `PARAM` ใน `guard.js` |
| Adaptive behaviour: ระดับเตือนภัยเพิ่มขึ้นทุกครั้งที่ถูกเห็น | `rangeNow`, `G.alert` |
| Stigmergy (ทางอ้อม): รอยกลิ่นที่ผู้เล่นทิ้งไว้ให้หมาตาม | `G.trail`, state `track` |
| **รายงานหลังจบด่าน**: เส้นเวลาสถานะของยามแต่ละคน และข้อความ CFP / bid / award / relay / alarm บันทึกเป็นรูปได้ | `js/summary.js` |
| Pathfinding: BFS 8 ทิศ + path smoothing | `js/world.js` |

```
js/audio.js     เสียงและดนตรี (WebAudio)

js/guard.js     สมอง agent ของยาม
js/render.js    กราฟิกทั้งหมด (canvas)
js/summary.js   กราฟสรุปหลังจบด่าน
js/game.js      ลูปเกม UI ร้านค้า โหมดต่าง ๆ
```
